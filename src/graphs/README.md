2. When should you BFS vs DFS a graph? Why?

Use Breadth-First Search (BFS) (using a queue) to find the shortest path in unweighted graphs or when the target is near the source. Use Depth-First Search (DFS) (using a stack/recursion) for exploring deep paths, topological sorting, detecting cycles, or when memory is limited
