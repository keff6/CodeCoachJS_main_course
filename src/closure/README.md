# Written Response
## My response:

A closure is a function inside a function that has access to all its lexical scope, in other words, its own parameters, the outer function parameters and variables and global variables.

## Improved response:

A closure is a function defined inside another function that retains access to its lexical scope, even after the outer function has finished executing. This includes its own variables and the variables of the outer function.
